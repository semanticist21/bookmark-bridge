Set up Bridgey

Bridgey needs a small MCP server on this computer. Your MCP client starts it for you.

1. Add the MCP server

Claude Code

claude mcp add bookmark-bridge -- npx -y bookmark-bridge@native

Codex — ~/.codex/config.toml

[mcp_servers.bookmark-bridge]
command = "npx"
args = ["-y", "bookmark-bridge@native"]

Other clients

{
  "mcpServers": {
    "bookmark-bridge": {
      "command": "npx",
      "args": ["-y", "bookmark-bridge@native"]
    }
  }
}

Requires Node.js and git on your PATH.

2. Restart the MCP client

On its first start, the server registers itself with Chrome.

This is an unpacked copy of Bridgey, so register its ID too:

3. Choose Native Messaging

Set Mode to Native Messaging in this popup and allow the permission Chrome asks for. Then ask your client to run bridge_status.

Use Legacy (WebSocket) instead

Register npx -y bookmark-bridge without @native, and keep Mode on Legacy. The port must match the server (8787 by default).
